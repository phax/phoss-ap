phoss AP - Peppol Access Point

A complete open-source Peppol Access Point based on phase4.

This server has no user interface – it only offers HTTP APIs:

  • /management/status – status, version and configuration overview
  • /actuator/health – Spring Boot health check
  • /openapi/v3/api-docs (YAML) – OpenAPI specification of all APIs
  • /as4 – the Peppol AS4 receiver endpoint (POST only)

All /api/** endpoints require the X-Token HTTP header.

See the project page and the wiki for details.
